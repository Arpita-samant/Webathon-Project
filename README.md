# Webathon Project

This repository holds the code for a project built during a Webathon hackathon.

The main goal was to build a simple, working web app in a short amount of time. The focus was on making a clean layout, ensuring it works on mobile and desktop, and keeping the code easy to follow.

Features:

* Simple design that is easy to navigate
* Works on mobile and desktop browsers
* Fast loading with clean code

Technologies used:

* HTML, CSS, JavaScript
* Git and GitHub
* Artificial Intelligence

How to run it locally:

1. Clone the repository:
git clone [https://github.com/Arpita-samant/Webathon-Project.git](https://github.com/Arpita-samant/Webathon-Project.git)
2. Open the project folder:
cd Webathon-Project
3. View the site:
Double-click the index.html file to open it in your web browser, or use the VS Code Live Server extension.

Project structure:

* index.html: Main page
* style.css/: Styling files
* script.js/: JavaScript files
* cognizance-bg.js/ Moving Background video file
* images and videos are uploaded in main file
